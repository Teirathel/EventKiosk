# Privacy Policy – Event Kiosk

Effective Date: 2026

This Privacy Policy describes how Event Kiosk ("the Bot") handles data.

## 1. Data Collection

The Bot does NOT collect, store, or process personal data outside of Discord.

The Bot only temporarily processes:
- Event title
- Date and time
- Event details
- Optional link
- User ID of the event creator

This data is used solely to:
- Create a Discord scheduled event
- Post an announcement message

## 2. Data Storage

Event Kiosk does NOT:
- Store user data in databases
- Log personal messages
- Track user activity
- Collect analytics

All data remains within Discord’s infrastructure.

## 3. Third-Party Services

The Bot operates using:
- Discord API

No additional third-party tracking services are used.

## 4. Data Retention

The Bot does not retain user-submitted information after event creation.
Event data exists only within Discord’s own scheduled event system.

## 5. Security

The Bot does not expose user data publicly.
Bot tokens and credentials are stored securely in environment variables.

## 6. User Rights

Since the Bot does not store personal data externally, there is no separate data to request, modify, or delete.

Users may remove events directly within Discord.

## 7. Changes to Policy

This Privacy Policy may be updated if functionality changes.

## 8. Contact

For privacy concerns, contact the repository owner via GitHub.
